## ما هو .s؟

أداة مجانية لتشفير الملفات تعمل في المتصفح مباشرة. جميع العمليات تحدث محلياً على جهازك — لا يتم إرسال أي بيانات لأي سيرفر.

- تشفير أي ملف أو مجلد
- امتداد الملف المشفر: `.s`
- قابل لفك التشفير بأي جهاز آخر يدعم الموقع

## المميزات

| الميزة | التفاصيل |
|--------|----------|
| التشفير | AES-256-GCM (المستوى العسكري) |
| اشتقاق المفتاح | PBKDF2 بـ 500,000 دورة |
| الملح (Salt) | 32 بايت عشوائي لكل تشفير |
| IV | 12 بايت عشوائي |
| المجلدات | ضغط ZIP قبل التشفير |
| اللغات | العربية + الإنجليزية |
| السيرفر | لا يوجد — يعمل بالكامل في المتصفح |

## كيفية الاستخدام

### التشفير
1. افتح الموقع في المتصفح
2. اسحب ملفك أو انقر لاختياره
3. أدخل كلمة مرور قوية
4. اضغط "تشفير الملف"
5. حمّل الملف بامتداد `.s`

### فك التشفير
1. انتقل لتبويب "فك التشفير"
2. اسحب الملف المشفر أو اختره
3. أدخل كلمة المرور
4. اضغط "فك التشفير"
5. حمّل الملف الأصلي

## كيف يعمل التشفير

```
الملف الأصلي
    ↓
导入 المفتاح من كلمة المرور (PBKDF2 + Salt)
    ↓
تشفير AES-256-GCM مع IV عشوائي
    ↓
تنسيق الملف النهائي:
┌────────┬──────────┬──────────┬──────────┬───────┬─────┬────────────┐
│ MAGIC  │ VERSION  │ NAME_LEN │ FILENAME │ SALT  │ IV  │ ENCRYPTED  │
│ 4 byte │ 4 byte   │ 4 byte   │ variable │32 byte│12 B │ variable   │
└────────┴──────────┴──────────┴──────────┴───────┴─────┴────────────┘
    ↓
الملف المشفر (.s)
```

## الأمان

- لا يوجد سيرفر — كل شيء يحدث في المتصفح
- AES-256-GCM مع مصادقة (Authenticated Encryption)
- PBKDF2 بـ 500,000 دورة لمقاومة هجمات القاموس
- ملح و IV عشوائي فريد لكل تشفير
- لا يتم حفظ أي كلمة مرور
