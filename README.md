## ما هو .s؟

أداة مجانية لتشفير الملفات تعمل في المتصفح مباشرة. جميع العمليات تحدث محلياً على جهازك — لا يتم إرسال أي بيانات لأي سيرفر.

- تشفير أي ملف أو مجلد
- امتداد الملف المشفر: `.s`
- قابل لفك التشفير بأي جهاز آخر يدعم الموقع

## المميزات

| الميزة | التفاصيل |
|--------|----------|
| التشفير | AES-256-GCM (المستوى العسكري) |
| اشتقاق المفتاح | Argon2id مع PBKDF2 كبديل |
| الملح (Salt) | 32 بايت عشوائي لكل تشفير |
| IV | 12 بايت عشوائي لكل جزء |
| المجلدات | تشفير كل ملف بشكل منفصل بدون ضغط ZIP |
| اللغات | العربية + الإنجليزية |
| السيرفر | لا يوجد — يعمل بالكامل في المتصفح |

## كيفية الاستخدام

### التشفير
1. افتح الموقع في المتصفح
2. اسحب ملفك أو انقر لاختياره
3. أدخل كلمة مرور قوية
4. اضغط "تشفير الملف"
5. حمّل الملف بامتداد `.s`

### فك التشفير
1. انتقل لتبويب "فك التشفير"
2. اسحب الملف المشفر أو اختره
3. أدخل كلمة المرور
4. اضغط "فك التشفير"
5. حمّل الملف الأصلي

## كيف يعمل التشفير

```
الملف/المجلد الأصلي
    ↓
اشتقاق المفتاح من كلمة المرور (Argon2id + Salt)
    ↓
تجزئة الملف لأجزاء بحجم 1MB
    ↓
تشفير كل جزء بـ AES-256-GCM مع IV عشوائي
    ↓
تنسيق الملف النهائي (.s):
┌─────────┬─────────┬───────────┬─────────┬─────┬──────────────────┐
│  MAGIC  │ VERSION │ FILE_COUNT│  SALT   │ IV  │  ENCRYPTED DATA  │
│ 4 byte  │ 4 byte  │  4 byte   │ 32 byte │12 B │   (per file)     │
└─────────┴─────────┴───────────┴─────────┴─────┴──────────────────┘

ملاحظة: الملفات تُخزّن بشكل منفصل داخل الحاوية
بدون ضغط ZIP — ZIP يُستخدم فقط عند التحميل كحل بديل
لعدم دعم المتصفحات لتحميل الفولدرات مباشرة
```

## الأمان

- لا يوجد سيرفر — كل شيء يحدث في المتصفح
- AES-256-GCM مع مصادقة (Authenticated Encryption)
- Argon2id لمقاومة هجمات القاموس والكمومية
- ملح و IV عشوائي فريد لكل تشفير
- لا يتم حفظ أي كلمة مرور
